**StudyBuddy** is a full-stack, AI-powered study platform designed to transform raw study materials (PDFs, notes, documents) into interactive quizzes, flashcards, mind maps, and a grounded RAG (Retrieval-Augmented Generation) AI teaching assistant.

Powered by **Google Gemini 1.5 Flash** with built-in client/server fallback engines, StudyBuddy delivers instant, context-aware study aids with direct page citations, detailed explanations, and comprehensive learning analytics.

---

## 🌟 Key Features

### 📄 1. PDF & Document Processing
- Upload PDF study materials with real-time text parsing via backend `pdf-parse`.
- Automatic metadata extraction: page count, estimated reading time, word count, file size, and text preview.
- Local fallback parser ensures seamless functionality even offline or without a backend connection.

### 🧠 2. AI-Grounded Quiz Generator
- Generate quizzes grounded strictly in your uploaded study notes using **Google Gemini 1.5 Flash**.
- **Multiple Question Types**: Multiple Choice (MCQ), True/False, Fill in the Blanks, and Short Answer.
- **Customizable Quiz Settings**:
  - Difficulty Levels: Easy, Medium, Hard.
  - Question Counts & Timed Quiz Mode (with toggleable countdown timers).
  - Multi-language Support: English, Tamil, Hindi, Spanish, French.
  - Topic focus filtering and option/question randomization.
- **Detailed Distractor Explanations**: "Why other options are wrong" breakdowns for deeper conceptual clarity.
- Direct **Page Citations** for every generated question.

### 🤖 3. RAG "Friendly Teacher" AI Assistant
- Interactive study chatbot acting as a warm, patient virtual tutor.
- Answers student questions using RAG (Retrieval-Augmented Generation) grounded strictly in active document text.
- Provides precise page references and snippet citations to verify answers.

### 🎴 4. Interactive Study Tools
- **Flashcard Revision Deck**: Interactive flip cards categorized by topic with mastery tagging (Mastered / Review Needed).
- **Mind Map Visualization**: Hierarchical node tree mapping core study concepts and sub-topics.

### 📊 5. Learning Analytics & Gamification
- Interactive progress charts built with **Recharts**:
  - Weekly quiz performance trends.
  - Topic-wise accuracy breakdown.
  - Performance by difficulty level.
- Cumulative study stats: total study time, quizzes completed, overall accuracy.
- **AI Recommendations**: Dynamic study advice based on performance metrics.
- **Gamified Achievements**: Unlockable badges for study milestones (e.g., *First Quiz Passed*, *Study Streak*, *Master Mind*).

### 🔐 6. User Authentication & Profile Customization
- Express authentication system with **Gmail validation** (`@gmail.com`).
- Profile management with customizable avatars, study goals, preferred difficulty, and notification settings.
- Dark mode toggle with instant global UI updates.

## 🏗️ System Architecture

```
                                  +-----------------------+
                                  |   React 18 Frontend   |
                                  | (TypeScript + Vite)   |
                                  +-----------+-----------+
                                              |
                                HTTP REST API | Axios / Fetch
                                              v
                                  +-----------------------+
                                  |   Express.js Server   |
                                  |      (Port 5000)      |
                                  +-----+-----------+-----+
                                        |           |
               +------------------------+           +-----------------------+
               |                                                            |
               v                                                            v
+-------------------------------+                            +-------------------------------+
|    Google Gemini 1.5 Flash    |                            |       pdf-parse Engine        |
|  (Quiz Gen & RAG Assistant)   |                            |   (PDF Text & Meta Extract)   |
+-------------------------------+                            +-------------------------------+
```

### Hybrid Fallback Architecture
StudyBuddy is built with high availability in mind:
- **Online Mode**: Communicates with the Node.js Express server to leverage `pdf-parse` and **Google Gemini 1.5 Flash API**.
- **Offline / Standalone Mode**: Automatically falls back to client-side parsers and intelligent template generators if the backend or Gemini API key is unavailable.

## 🚀 Getting Started

### Prerequisites
- **Node.js**: `v18.0.0` or higher
- **npm**: `v9.0.0` or higher
- **Google Gemini API Key** *(Optional, fallback engine activates if omitted)*: Get your free API key at [Google AI Studio](https://aistudio.google.com/).

### Installation

1. **Clone the repository** (or navigate to project directory):
   ```bash
   cd "STUDY BUDDY"
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Create a `.env` file in the root directory:
   ```env
   PORT=5000
   GEMINI_API_KEY=your_google_gemini_api_key_here
   ```

---

## 🛠️ Running the Application

### Option A: Running Full Stack (Frontend + Backend)

1. **Start the Express API Server**:
   ```bash
   npm run server
   ```
   *Server runs at `http://localhost:5000`*

2. **Start the Vite Frontend (in a second terminal)**:
   ```bash
   npm run dev
   ```
   *Frontend app opens at `http://localhost:5173`*

### Option B: Running Frontend Only (Standalone Mode)
If you only start the frontend without the backend server:
```bash
npm run dev
```
The app will operate seamlessly using built-in client-side fallback engines for document parsing, quiz generation, and chat responses.

## 🔌 API Documentation

| Method | Endpoint | Description | Request Payload | Response |
| :--- | :--- | :--- | :--- | :--- |
| `GET` | `/api/health` | Health & Gemini status check | None | `{ status: "ok", geminiConfigured: boolean }` |
| `POST` | `/api/auth/register` | Register new user account | `{ name, email, password }` | `{ success: true, user: UserProfile }` |
| `POST` | `/api/auth/login` | Authenticate user login | `{ email, password }` | `{ success: true, user: UserProfile }` |
| `POST` | `/api/upload-pdf` | Upload & extract PDF text | Multipart Form (`pdf` file) | `{ filename, text, pageCount, ... }` |
| `POST` | `/api/generate-quiz` | AI Quiz generation | `{ documentText, questionCount, difficulty, documentName }` | `{ success: true, questions: Question[] }` |
| `POST` | `/api/chat-assistant` | Grounded RAG Chat bot | `{ question, activeDocumentText, documentName }` | `{ reply: string, source: string }` |
